# Verification evidence

- `demo-report.json` is generated by `npm run demo`. It records actual MCP
  subprocess calls against an authenticated local provider with ten fictional
  tickets, including a timed HTTP 429 recovery.
- `test-results.txt` records the test-runner output from the submission
  verification run.

No live account, customer data, LLM, or hosted Agent Studio tenant is used in the
offline verification. Demo credentials are generated in memory for each run and
are never written to these artifacts.

Reproduce the checks with `npm ci --ignore-scripts` and `npm run verify`.
